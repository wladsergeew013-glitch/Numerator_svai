# История версий

## 0.3.2 — 14 ноября 2026

Полный проход по реестру PN-001–PN-074 и трём отдельным TD-пунктам. По каждому ID приведены изменение, проверка и границы приёмки в [отчёте](docs/FULL_REVIEW_RU.md).

- Записи одной сессии проходят общую очередь; карточка сваи и редакторы проверяют владельца перед применением позднего ответа. Все ручные связи проверяются вместе; диагностика номеров учитывает pipeline/per_group. Косметические изменения не запускают пересчёт маршрута. SDK cache безопасно публикуется двумя процессами.
- Импорт различает CAD-объекты с равными XY, проверяет конечность чисел, структуру и ссылки JSON. CSV сохраняет первую строку данных и переводы строк в кавычках; политика заголовка переключается в preview. Из координат вычитается база.
- Excel использует официальную SheetJS 0.20.3 в отдельном worker; числовые координаты читаются без округления по формату отображения ячейки. Worker поддерживает отмену и deadline. Связанные участки тоже рассчитываются вне UI-потока.
- Черновики закреплены за сессией и группой; массовые ручные операции сохраняют locked-точки. Видимость, кнопки мыши, Ctrl/Shift и ортогональное построение обрабатываются согласованно.
- Настройки сохраняются точными PATCH под межпроцессной блокировкой; исключены чтение и отправка старой полной копии, повторная миграция выбранных цветов/шрифтов и перестановка dock-панелей при resize. Снимки журнала ограничены и удаляются вместе с недоступными записями.
- Добавлены хранение, назначение, отображение и удаление пользовательских иконок; финальная визуальная приёмка/restart EXE отмечена отдельно. Runtime paths, имя файла Windows и выбор EXE_ICON используются согласованно.
- HTTP API требует ключ локальной сессии, проверяет peer/Host/Origin и ограничивает тело до parser. Обновлены совместимые FastAPI/Starlette/multipart и зависимости сборки. Docker публикует порты на loopback и сохраняет данные в постоянном томе; добавлены backup/restore/migration.
- CAD-экспорт заранее проверяет однозначность сопоставления, актуальные координаты и GUID базы, пишет только итоговый номер, проверяет readback и инвалидирует snapshot при попытке записи. Фатальные ошибки останавливают пакет с частичными счётчиками. Закрытие согласовано с worker и cancellation marker.
- Исправлены single-group HTTP rows и три неиспользуемых модуля; они не подключены к интерфейсу.

COM/NRX и запись/сохранение/повторное открытие настоящего DWG требуют отдельной приёмки на nanoCAD. Изолированные CAD-модели и timing-модель не заменяют эту проверку. Исходник NRX не менялся; встроенный модуль совместимого протокола переиспользуется с раскрытой контрольной суммой сборки.

## 0.3.1 — 14 ноября 2026

Первый опубликованный Windows-релиз с исправлениями по ревью версии `520515f`.

- Сохранение защищено от конкурирующих запросов и нескольких процессов. Файл с BOM можно сохранить повторно; переименование A → B → A сохраняет принадлежность проекта.
- Открытие другого проекта запрашивает решение о несохранённых изменениях. История и черновики изолированы по файлам; запоздавшие ответы открытия, сохранения и импорта проверяются перед применением.
- Автонумерация резервирует закреплённые номера. Кластерный префикс не добавляется повторно; ручной итоговый номер отделён от локального счётчика.
- Исправлены продолжение групп, ручной финиш, обновление маршрутов, выбор пайплайна и команды для заблокированных или пустых групп.
- Диалоги и текстовые поля получают приоритет клавиатуры перед рабочим полем. Исправлен сброс file input стартового экрана после чтения файла.
- Добавлена новая контрастная иконка с семью размерами от 16 до 256 пикселей. Версия отображается согласованно в интерфейсе, API и свойствах EXE.
- Добавлены автоматические проверки Windows и Linux в GitHub Actions. Тесты выбора пути используют канонический регистр пути и не меняют платформу для всего процесса Python.

Исправлены PN-001–PN-018, PN-020, PN-040, PN-041 и PN-052. Проверка переносимости тестов PN-068 включена в CI. Полный статус и сценарии: [исправления по ревью](docs/REVIEW_FIXES_RU.md).

Проверены 88 Python-тестов, восемь contract/workflow checks и 192 сочетания нумерации с повторным запуском каждого. Windows-сборка проверена запуском WebView2 и конкурентным сохранением через её HTTP API. Настоящий обмен с nanoCAD/Model Studio и запись DWG в этой версии отдельно не принимались. NRX-модуль переиспользуется из прежней локальной установки без изменений; версия не закрывает весь реестр замечаний.
