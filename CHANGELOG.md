# История версий

## 0.3.1 — 14 ноября 2026

Первый опубликованный Windows-релиз с исправлениями по ревью версии `520515f`.

- Сохранение защищено от конкурирующих запросов и нескольких процессов. Файл с BOM можно сохранить повторно; переименование A → B → A сохраняет принадлежность проекта.
- Открытие другого проекта запрашивает решение о несохранённых изменениях. История и черновики изолированы по файлам; запоздавшие ответы открытия, сохранения и импорта проверяются перед применением.
- Автонумерация резервирует закреплённые номера. Кластерный префикс не добавляется повторно; ручной итоговый номер отделён от локального счётчика.
- Исправлены продолжение групп, ручной финиш, обновление маршрутов, выбор пайплайна и команды для заблокированных или пустых групп.
- Диалоги и текстовые поля получают приоритет клавиатуры перед рабочим полем. Исправлен сброс file input стартового экрана после чтения файла.
- Добавлена новая контрастная иконка с семью размерами от 16 до 256 пикселей. Версия отображается согласованно в интерфейсе, API и свойствах EXE.
- Добавлены автоматические проверки Windows и Linux в GitHub Actions. Тесты выбора пути используют канонический регистр пути и не меняют платформу для всего процесса Python.

Исправлены PN-001–PN-018, PN-020, PN-040, PN-041 и PN-052. Проверка переносимости тестов PN-068 включена в CI. Полный статус и сценарии: [исправления по ревью](docs/REVIEW_FIXES_RU.md).

Проверены 88 Python-тестов, восемь contract/workflow checks и 192 сочетания нумерации с повторным запуском каждого. Windows-сборка проверена запуском WebView2 и конкурентным сохранением через её HTTP API. Настоящий обмен с nanoCAD/Model Studio и запись DWG в этой версии отдельно не принимались. NRX-модуль переиспользуется из прежней локальной установки без изменений; версия не закрывает весь реестр замечаний.
