## Нумерация и группы

| Пункты | Изменение | Проверка |
| --- | --- | --- |
| PN-008, PN-009 | Префикс применяется только к рассчитанным свободным точкам. Итоговый ручной номер не используется как локальный счётчик. | Повторная нумерация, закрепление показанного номера 22 в кластере 2, произвольный ручной итоговый номер 999. |
| PN-010 | Копирование группы и назначение используют общую проверку блокировок точки, прежней группы и группы назначения. | Запрет переноса из заблокированной группы, в неё и изменения принадлежности закреплённой точки. |
| PN-011 | Закреплённые и ручные номера резервируются до назначения свободных. Для «Все» новые номера резервируются в ходе расчёта. | Закреплённая точка до/после свободных, поздняя заблокированная группа, независимые пайплайны. |
| PN-012 | Ручная связь не может привести к закреплённому финишу раньше остальных точек. | Четыре метода, загрузка ранее сохранённой несовместимой связи и создание связи через store. |
| PN-013, PN-014 | Закреплённый кластер не продвигает обычный счётчик. per_group не наследует геометрическое продолжение предыдущей группы ни в применении, ни в предпросмотре. | Смена lock без сдвига последующей обычной группы, совпадение «Группа», «Все», preview и flow. |
| PN-015, PN-016 | Проверка ручной связи использует контекст продолжения. Производный маршрут обновляется при смене точек, групп, пайплайнов, режима и Undo; камера его не меняет. | Изменение метода, состава, координат и Undo; допустимое направление связи после предыдущей группы. |
| PN-017, PN-018 | Явно выбранная пустая группа не подменяется соседней. Копирование группы меняет одновременно выбранную группу и её пайплайн. | Пустая активная группа и копирование между двумя пайплайнами. |
| PN-020 | Отклонённая из-за lock очистка не меняет связи и не записывает успех в журнал. | Блокировка группы после открытия очистки. |

Политика нумерации: занятые закреплёнными точками номера пропускаются. Пространство номеров — пайплайн для global_sequential и группа для per_group. Независимые пайплайны могут иметь одинаковые номера. В кластере ручной ввод означает итоговый номер. Сохранённый local используется только при проверенном соответствии prefix/local/final; произвольный итоговый номер занимает одну позицию локального обхода. Цифры префикса из введённого номера не отрезаются.

Расчёт небезопасного целого диапазона прекращается до записи точек и истории. Полная валидация полей ввода PN-019 остаётся отдельной работой.
