# Полный реестр ревью — v0.3.2

Дата: 14 ноября 2026 года. Исходное ревью: `520515fc651750d9a24d812bc029618b399f3ecb`. Проверенная исходная версия этого прохода: `0b8e101c64d1104283c82cfe115ef8f280aa2888` (v0.3.1). Ветка: `codex/full-review-fixes`.

Объединены оба ревью: все 74 основных пункта и 3 TD (77 ID). 17 пунктов уже полностью исправлены в исходном HEAD v0.3.1 и повторно проверены. Остальные 57 основных пунктов и 3 TD обработаны в этом проходе, включая уточнения частичных исправлений. Для PN-029–PN-039 и PN-072 нужна настоящая приёмка CAD; для PN-054 и PN-063 остаётся финальная проверка UI/перезапуска frozen EXE. Эти 14 пунктов имеют ограниченный статус. Автоматические, процессные и Docker-проверки не выдаются за работу в настоящем CAD или визуальный E2E.

## Как воспроизвести проверки

- **T**: `backend/.venv/Scripts/python.exe -m unittest discover -s tests -q` — 111 тестов; новые контрпримеры в `tests/test_review_fixes.py`, прежние проверки не исключались. Linux запускает тот же suite в Python 3.12 Docker image.
- **S**: `node tools/checks/project_session_check.cjs` — настоящие store/React-обработчики с управляемым транспортом, jsdom для keyboard/modal; это не полный browser E2E.
- **N**: `node tools/checks/transfer_regression_check.cjs` — матрица закреплённых номеров: 192 сочетания × 2 запуска, плюс конкретные контрпримеры передачи/нумерации.
- **K**: `node tools/checks/cad_scan_workflow_check.cjs` — настоящие frontend CAD-обработчики с моделью транспорта.
- **F**: `node tools/checks/full_review_check.cjs` — настоящий store, runtime parsers и извлечённые AST-обработчики интерфейса; не визуальный E2E.
- **W**: `node tools/checks/worker_import_check.cjs` после production build — настоящие Vite worker bundles в Node worker_threads.
- **D**: `backend/.venv/Scripts/python.exe tools/checks/docker_persistence_check.py` — настоящий Docker save/recreate/reopen, собственный временный volume.
- Остальные штатные checks: `production_api_check.cjs`, `desktop_startup_check.cjs`, `operation_log_check.cjs`, `vite_dev_check.cjs`, `frontend_contract_check.py`, `locked_state_contract_check.py`. Всего 11 frontend/desktop checks.
- `npm ci --prefix frontend`, `npm run build --prefix frontend`, `npm audit --prefix frontend`, `backend/.venv/Scripts/python.exe -m pip check`.

Обозначение «уже исправлено» относится к исходному HEAD v0.3.1, а не означает новое изменение этого прохода. В таблице результат указан для конкретного контрпримера; общие эксплуатационные ограничения перечислены отдельно.

## Безопасность и зависимости

Для PN-057–PN-060 применён skill `codex-security:fix-finding`: отдельная проверка исходного пути и один независимый read-only review кандидата.
